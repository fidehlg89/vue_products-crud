# 🚀 Modern Product Management System (Vue 3)

A premium, high-performance Product CRUD application built with **Vue 3 (Composition API)** and **Vite**, featuring a stunning modern UI with rich aesthetics.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Vue](https://img.shields.io/badge/vue-3.x-brightgreen.svg)
![Vite](https://img.shields.io/badge/vite-4.x-purple.svg)

## ✨ Features

- **Vue 3 Composition API**: Clean, modern, and maintainable code structure using `<script setup>`.
- **Premium UI/UX**: Glassmorphic elements, smooth transitions, and a curated color palette (HLS).
- **Full CRUD Support**: Effortlessly add, view, update, and delete products.
- **Micro-animations**: Subtle feedback for every user interaction.
- **Responsive Design**: Optimized for all screen sizes.
- **Backend Connectivity**: Seamlessly integrates with a Flask-based API.

## 🛠️ Technology Stack

- **Frontend**: Vue.js 3, Vite, Axios, Bootstrap Icons.
- **Styling**: Vanilla CSS with modern variables & HLS color system.
- **Design System**: Plus Jakarta Sans typography, Shadow-driven depth, and accent colors.

## 🚀 Getting Started

### Prerequisites

- Node.js (v16+)
- Yarn or NPM

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/premium-products-crud.git
   cd premium-products-crud
   ```

2. **Install dependencies**
   ```bash
   yarn install
   ```

3. **Run the development server**
   ```bash
   yarn dev
   ```

4. **Access the application**
   Open `http://localhost:5173` in your browser.
